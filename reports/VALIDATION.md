# Проверка приложения

Дата: 18 октября 2026 года. Приложение рассчитано на локальную работу с Python 3.11+; проверенная среда — Python 3.12.14, PyTorch 2.14.1+cpu, OpenCV 5.0.0, FastAPI 0.146.0, React 19.2.0, TypeScript 5.9.3, Vite 7.2.2. Полные версии — в requirements-lock.txt и frontend/pnpm-lock.yaml.

## Автоматические проверки

`python -m pytest -q --basetemp=.test-tmp-release`: 22 проверки — математика известных синтетических координат, знак canthal tilt при y вниз, инвариантность к переносу/масштабу/повороту, обратимость аффинного crop, инволюция и биективность индексов отражения для 68/98 точек, градиенты обеих CNN для обоих форматов, NME и порог Failure Rate, отпечатки manifest AFW/WFLW и отсутствие пересечения снимков между тремя выборками.

API проверяется без production checkpoint: предобработка доступна, инференс возвращает 503; никакого шаблона вместо предсказания. Проверяются границы ROI, NaN, неверный формат, повреждённое изображение, лимит 10 МБ, EXIF и Cache-Control. Синтетические координаты используются исключительно в тестах геометрии и не выводятся в приложении как результат ML.

Установленная версия Starlette предупреждает о будущем переходе TestClient с httpx на httpx2. Это предупреждение совместимости тестового клиента, не ошибка тестов. В ограниченной Windows-песочнице создание сетевых потоков TestClient блокировалось; тесты и localhost-сервер успешно выполнялись с разрешённым локальным запуском вне этих сетевых ограничений.

Сборка `pnpm build` включает строгую проверку TypeScript и производственную сборку Vite. Интерфейс использует Tailwind CSS, без удалённых шрифтов, аналитики и внешнего AI. Проверены обработка устаревших запросов при смене фото, очистка Object URL, остановка MediaStream, клавиатурные числовые поля ROI, подписи элементов, focus-visible и reduced-motion.

## Реальный HTTP и браузер

`scripts/check_live.py` обращается к работающему серверу и отправляет два разных снимка отложенной выборки. ROI для этого диагностического запуска берётся из разметки, **только как область кадрирования**. Предсказанные ориентиры всегда даёт CNN. Проверяются 7 фактических этапов, полное число точек, конечные значения, повторяемость результата и различие нормализованных предсказаний между снимками. Сводка последнего запуска — `qa/api-smoke.json`.

В браузере проверены открытие страницы и загрузка реальной фотографии из AFW; получены кадр 96×96, наложенные точки, измерения, предупреждения и фактические сведения семи этапов. Отдельно визуально проверена русская версия страницы загрузки. Снимок экрана: `qa/interface-ru.png`. В интерфейсе работает ручное выделение лица; выбор только узкой полосы глаз некорректен и не соответствует обучающему crop.

Мобильная компоновка реализована CSS-медиазапросами, но отдельная аппаратная проверка телефона не проводилась. Аппаратная камера и её разрешение не проверялись автоматически; приложение использует настоящий getUserMedia, останавливает поток при закрытии окна и показывает ошибку при отказе. Проверка на новых добровольческих фото требует разрешения владельцев и не подменяется результатом на датасете.

## Данные и ограничения

Пользовательские фотографии читаются ограниченным потоком в память; UploadFile/multipart и дисковый spooling не используются. Персистентные данные обучения находятся отдельно от runtime. Нет endpoint для сохранения фото, каталога пользовательских загрузок, идентификации лиц или базы биометрических эмбеддингов. Экспорт JSON вызывается только кнопкой и исключает фото.

Производственная модель загружается только из локального checkpoint с метаданными случайной инициализации, положительным числом шагов и результатом независимого теста. Повреждённый/отсутствующий файл блокирует инференс. Это проверка совместимости и происхождения локального артефакта, не криптографическое доказательство авторства любого произвольного файла.

Проверки работоспособности не доказывают точность измерений. Количественные ограничения модели, ошибки углов и отношений, базовый шаблон и реальный тест приведены отдельно в RESEARCH.md.
