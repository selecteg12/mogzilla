# Перенос и публикация

Подготовлена сборка одного приложения: React и Python API работают на одном домене, обе CNN выполняются на CPU сервера. Браузер отправляет фото этому серверу по HTTPS; приложение использует память и не сохраняет снимки. Внешний AI API не нужен. После публикации обработка происходит на хостинге, а не на компьютере посетителя.

## Комплект

- `Dockerfile`: сборка React через Node 24 и pnpm, затем Python 3.12 с CPU PyTorch; запуск от отдельного пользователя.
- `requirements-runtime.txt`: версии библиотек инференса без инструментов обучения и тестирования.
- `pyproject.toml` и `vercel.json`: Python 3.12, тот же набор зависимостей, CPU PyTorch из официального индекса, сборка React и проверка комплекта для Vercel Functions. `.vercelignore` ограничивает отправку с локального компьютера.
- `scripts/serve.py`: проверка интерфейса, загрузки обеих моделей и соответствия фотопримеров текущим весам/формуле. При неполном комплекте запуск завершается с ошибкой.
- `.github/workflows/verify.yml`: сборка контейнера на Linux и проверка запущенного приложения, включая поиск 98 точек и расчёт балла на одном фотопримере. Выполняется после push и в pull request.
- `render.yaml`: вариант ручного запуска Docker Web Service на бесплатном плане Render. Автоматические публикации выключены.
- `.dockerignore`: в образ попадают исходники инференса, интерфейс, две активные модели и фиксированная галерея. Датасеты, архивы, личные проверки, окружения и экспериментальные веса исключены.

## Проверка и запуск

Из корня проекта с установленными зависимостями и собранным интерфейсом:

```powershell
.\.venv\Scripts\python.exe -m scripts.serve --check
```

На компьютере с Docker:

```text
docker build -t facemetrics-ai .
docker run --rm -p 8000:8000 facemetrics-ai
```

Контейнер слушает `0.0.0.0`, по умолчанию порт 8000; хостинг может задать `PORT`. Запускается один процесс с ограничением параллельных запросов. Проверка доступности: `/api/health`; состояние моделей: `/api/model`. Затем нужно проверить загрузку фотографии, ответ `/api/localize`, балл и три примера `/api/reference-values` по реальному адресу хостинга.

Проверка адреса без сторонних Python-библиотек:

```text
python scripts/check_deployment.py https://your-app.example
```

Проверка отправляет только уже опубликованный фотопример. Его увеличенный фрагмент анализируется как новая фотография, поэтому балл не должен обязательно совпадать с баллом исходного снимка в галерее.

Docker на рабочем компьютере отсутствует. Контейнер собран и запущен на Linux в [GitHub Actions для коммита a130307](https://github.com/selecteg12/facemetrics-ai/actions/runs/39341749418): проверены интерфейс, обе модели, три фотопримера, автоматический поиск 98 точек и расчёт рейтинга. Измеренные 257 МБ памяти процесса и пик 357 МБ относятся к локальному Windows-запуску; они не гарантируют, что все допустимые фотографии поместятся в лимит другого хостинга.

## Публикация

Код и активные модели загружены в закрытый репозиторий [selecteg12/facemetrics-ai](https://github.com/selecteg12/facemetrics-ai), ветка `master`. Настроен remote `origin`. Датасеты и `reports/qa/` исключены из Git и не должны добавляться принудительно. Две активные модели суммарно занимают около 4,3 МБ и не требуют Git LFS.

Для Render подключите репозиторий и создайте Blueprint из `render.yaml` либо Docker Web Service с этим Dockerfile. Бесплатные сервисы засыпают после 15 минут без запросов; первое открытие после сна может занять около минуты. На бесплатном плане 512 МБ памяти, поэтому перед публичным использованием нужно проверить большие фото и несколько запросов. См. [Docker на Render](https://render.com/docs/docker), [Blueprint](https://render.com/docs/blueprint-spec), [ограничения бесплатного плана](https://render.com/docs/free), [тарифы](https://render.com/pricing).

20 октября 2026 года приложение опубликовано на Vercel: **[https://facemetrics-ai.vercel.app](https://facemetrics-ai.vercel.app)**. Это публичный адрес, не требующий входа в Vercel. Проект `facemetrics-ai` принадлежит команде `selecteg12`; подключён репозиторий GitHub. Публикация выполнена официальным Vercel CLI после входа владельца аккаунта.

Используется [FastAPI на Vercel](https://vercel.com/docs/frameworks/backend/fastapi) без контейнерного реестра. В проекте включены Fluid compute и переменная конфигурации `VERCEL_SUPPORT_LARGE_FUNCTIONS=1` для production и preview. Это необходимо: начальная сборка с CPU PyTorch превысила стандартный предел 500 МБ. С включёнными [Python Functions до 5 ГБ в beta](https://vercel.com/docs/functions/limitations) сборка и загрузка обеих моделей прошли. Python-зависимости не содержат инструментов обучения, а для torch используется только официальный CPU-индекс.

Проверенный выпуск исходников `a130307`: `dpl_4BgE7vVv1HWMYLXqUjq3zNGU53a3`. Сначала API проверен через авторизованный `vercel curl` на защищённом адресе выпуска, затем выпуск назначен production командой `vercel promote`. Защита адресов отдельных выпусков сохранена; для посетителей используется публичный основной домен выше. Секреты CLI и локальный `.env.local` исключены из Git.

Исходный файл до 10 МБ приводится к JPEG. При необходимости качество сжатия снижается, пока запрос не поместится в 4 МБ, с учётом [ограничения Vercel 4,5 МБ](https://vercel.com/docs/functions/limitations). Разрешение фотографии сохраняется, поэтому исходное фото и точки используют одинаковые координаты. Если даже после сжатия лимит не соблюдается, приложение просит уменьшить разрешение. Сам backend при локальном запуске по-прежнему допускает бинарные запросы до 10 МБ.

Проверка публичного адреса без авторизации командой `python scripts/check_deployment.py https://facemetrics-ai.vercel.app` прошла: обе модели готовы, HTML и два основных файла интерфейса загружаются, доступны три фотопримера, повторный анализ первого фотопримера возвращает 98 точек и геометрический балл 9,17. Это проверка реального инференса на хостинге. Визуальная проверка через управляемый браузер не выполнена: доступ к домену был отклонён разрешениями браузера.

Используется существующий план Hobby. Платные ресурсы и обновление тарифа не заказывались. Первое обращение к Python-функции после простоя может занять больше времени, чем последующие запросы. Приложение не использует внешние AI API; геометрический рейтинг рассчитывается по явной формуле, а не является объективной оценкой привлекательности.
