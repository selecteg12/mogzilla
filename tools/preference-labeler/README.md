# Локальная разметка личной подборки

Браузерный просмотрщик без внешнего API. Загрузка нескольких фотографий или папки, точное устранение повторов по SHA-256, оценки 1–10, пропуск/исключение/отмена, сохранение фотографий и разметки в IndexedDB. Старый прогресс `facelab-review-20261020-batch1` переносится без удаления localStorage. Точная тестовая запись C012 из предыдущей проверки помечается для повторной оценки; более свежая личная оценка сохраняется.

Установка в существующую папку подборки:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m scripts.install_preference_labeler --directory "C:\path\to\collection"
.\.venv\Scripts\python.exe -m http.server 8002 --bind 127.0.0.1 --directory "C:\path\to\collection"
```

Открыть `http://127.0.0.1:8002/Просмотр.html`. Папка без `manifest.json` запускается как пустая подборка. Просмотрщик требует локальный HTTP-сервер; `file://` не поддерживается. Разметка в другом браузере/на другом origin — отдельная база. ZIP нужен для переносимой резервной копии.

Экспорт `FaceLab_dataset_*.zip`: исходные байты фотографий по папкам `photos/1`–`photos/10`, `unrated`, `excluded`, `needs-review`; `ratings.csv`; `manifest.json`, схема `facelab.personal-dataset`, версия 1. Подтверждённые человеческие баллы имеют `training_eligible=true`, остальные — пустой `score`. Предложения куратора сохраняются отдельно и не используются как метки. Архив можно восстановить в просмотрщике. Изображения проверяются по SHA-256 на экспорте и восстановлении. Формирование ZIP само по себе не запускает обучение. Перед обучением нужны проверка повторов людей, разделение на обучение/проверку и проверка условий использования источников.

Лимиты: 20 МБ/фото, 40 мегапикселей, 300 МБ/подборка, 2000 фото. Автосохранение зависит от доступности и квоты IndexedDB. Ошибки записи не меняют подтверждённое состояние в UI. Модель привлекательности для разметки не вызывается.

Проверка целостности экспорта и миграции:

```powershell
node --test tools/preference-labeler/core.test.mjs
```

ZIP: локальная копия fflate 0.8.3 из официального npm; SHA-512 архива сверена с метаданными npm. MIT-лицензия, источник и SHA-256 модуля — в `vendor/`. Во время работы загрузок с CDN нет.
