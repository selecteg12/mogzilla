# Pinterest portrait collection

`pinterest-portraits.zip` contains the additional portrait collection supplied for the project. The project maintainer identifies Pinterest as the image source and model scouts as the source of the confirmed ratings.

The archive contains original image bytes and a compact `manifest.json` with image IDs, relative paths, SHA-256 hashes, confirmed scores, review status and available source URLs. Excluded photographs have no training target. Automatically suggested scores, browser storage, local filesystem paths and working notes are not included.

This collection is separate from SCUT-FBP5500, MEBeauty, WFLW, AFW/300-W and WIDER FACE. Images from those research datasets are not included in this archive.

The collection is not a Pinterest-endorsed dataset. The original pin or creator URL is retained where it was present in the supplied records; complete per-image attribution is not available. Image rights remain with their respective owners. This repository does not grant an unrestricted license to third-party photographs. See [Pinterest's terms](https://policy.pinterest.com/en/terms-of-service) and the relevant original sources.
